03 · Projects

DevTITANS · UFAM, Motorola & Flextronics — capstone project (team of 6)

LoRa HAL for Android 14 (AOSP)

  • Problem

    Android has no native support for long-range, low-power LoRa communication with an external ESP32 + E32 radio connected over USB.

  • Action

    As AOSP developer, built the integration stack: USB kernel driver with sysfs interface, C++ vendor library, AIDL HAL (@VintfStability) with Binder daemon, SELinux and VINTF policies, Java manager and platform app, plus a sensors SubHAL with driver wakeup.

  • Result

    End-to-end messaging with AES key exchange validated between two physical LoRa nodes through QEMU USB passthrough; no SELinux denials and graceful operation when the hardware is disconnected.

  • AOSP
  • HAL
  • Binder
  • SELinux
  • Linux kernel

ACM · WSSE 2023 (Tokyo) & WSSE 2024 (Kyoto)

LinkDoc — Automated Carrier Documentation

  • Problem

    Carrier homologation needed 9 large documents for 3 Brazilian carriers, filled by hand, with frequent rejections and rework.

  • Action
